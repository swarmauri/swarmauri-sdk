# swarmauri_provider_qwen

## Features

- Qwen/DashScope authentication, endpoints, catalogs, errors, and schemas.
- Shared provider resource for Qwen model families.

## Installation

`uv add swarmauri_provider_qwen` or `pip install swarmauri_provider_qwen`.

## Usage

Inject `QwenProvider(api_key=...)` into a Qwen adapter.
