# swarmauri_live_model_xai

## Features

- xAI realtime text/audio sessions and function calls.
- Typed Swarmauri live events over WebSocket.

## Installation

`uv add swarmauri_live_model_xai` or `pip install swarmauri_live_model_xai`.

## Usage

Inject `XAIProvider` and consume events from `XAIRealtimeModel`.
