### Why This Package

`swarmauri_provider_xai` isolates this responsibility: Aggregated xAI provider resources for Swarmauri models. Its [package source](https://github.com/swarmauri/swarmauri-sdk/blob/master/pkgs/50-community/swarmauri_provider_xai/swarmauri_provider_xai/__init__.py) exposes `XAIAuthConfig`, `XAIEndpoints`, `XAIErrorMapper`, `XAIModelCatalog`, `XAIProvider`, `XAIToolSchemaConverter`, allowing consumers to select this package without treating adjacent packages as part of its public contract.

### When to Use

Choose `swarmauri_provider_xai` when your integration needs aggregated xAI provider resources for Swarmauri models. Match the imports below to your application boundary and install its declared dependencies before using the example.

### Features

- xAI authentication, endpoints, catalogs, errors, and tool schemas.
- Capability-aware chat, model-listing, and realtime connection configs.
- Runtime authorization with credentials excluded from serialized configs.
- Shared provider resource for xAI model families.

### Non-Goals

`swarmauri_provider_xai` owns aggregated xAI provider resources for Swarmauri models. Its imports do not by themselves configure credentials, deploy a service, or certify the behavior of its consumers. Dependencies and neighboring packages retain their own documented responsibilities.
